# Holler 设计规范（参考 Flyme Auto）

> ⚠️ **色彩令牌以代码为唯一事实来源**：[`app/src/main/java/com/vongzh/holler/ui/theme/Theme.kt`](../app/src/main/java/com/vongzh/holler/ui/theme/Theme.kt)。
> 本文档下方的色值表是 2026-10 之前的早期草案，**已过期**（例如 `bg_base` 现为 `#0B1117` 深色 / `#E2E9F1` 浅色，`accent` 现为 `#1AE5A3` 深色 / `#00B578` 浅色），
> 保留仅为记录设计推演过程。布局骨架图同样早于「单屏 + 底部 DOCK」的现状，最新版式见 README 与 `docs/AUDIT-2026-10-10.md`。

## 设计语言来源

Flyme Auto（领克 08 车机）的核心视觉特征：

| 特征 | 规范 |
|---|---|
| **布局** | 大卡片式（悬浮卡片），底部 DOCK 栏，左侧为加大的触控热区（SmartBar 思路） |
| **形状** | 全部控件与卡片为**统一 R 角的圆角矩形**，无例外；整体偏锐利直角倾向 |
| **质感分层** | 界面层级/背景 = **毛玻璃磨砂**；操作类控件 = **轻质感**；演示动画 = 重质感 |
| **图标** | 扁平化**线性**图标，统一线宽 |
| **配色** | 中性黑白灰为主 + 品牌色点缀；深色底 |
| **动效** | 物理仿真（轻微回弹/橡皮筋效果），克制 |

## Holler 色彩令牌

沿用 StayOta VI 的纪律：**1 个主色 + 语义色**，不做大面积铺色。

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg_base` | `#0A0F14` | 页面底色（比主色更深，车机夜间友好） |
| `brand` | `#0A2A43` | 品牌深海蓝，卡片/面板底 |
| `brand_elevated` | `#12314D` | 浮起卡片（毛玻璃近似层） |
| `accent` | `#21D4A5` | VI 辅助青绿，**仅用于关键动作与强调**（如喊话按钮激活态） |
| `danger` | `#C8324B` | 录音中/停止 |
| `text_primary` | `#F2F6F9` | 主文字 |
| `text_secondary` | `#8FA3B5` | 次要文字 |
| `stroke` | `#1E3A52` | 卡片描边（1dp） |

> 车机深色环境为主，故默认深色主题。品牌色 `#0A2A43` 作为"面"而非"点"，青绿 `#21D4A5` 只做"点"。

## 布局骨架（v0.3.1 三页导航）

```
┌─────────────────────────────────────────────────┐
│  Holler                          车外喊话  ● 待命 │  ← 顶栏（状态点常驻）
├─────────────────────────────────────────────────┤
│   ┌───────────────────────────────────────────┐ │
│   │        ╭─────────────────╮                │ │
│   │        │   [ 声波可视化 ] │  ← 倒计时环     │ │  ← 主卡片（毛玻璃）
│   │        │       剩 12 秒   │                │ │
│   │        ╰─────────────────╯                │ │
│   │              按住喊话                     │ │
│   │              准备就绪                     │ │
│   └───────────────────────────────────────────┘ │
│   ┌───────────────────────────────────────────┐ │
│   │  变声效果                        原声      │ │  ← 效果选择器
│   │  [原声][大叔][机器人][电音][萝莉]          │ │
│   └───────────────────────────────────────────┘ │
│   ┌───────────────────────────────────────────┐ │
│   │  音量与增益              ────●────  100%   │ │  ← 滑块 + 开关
│   │  自动增益 (AGC)                      [ON] │ │
│   └───────────────────────────────────────────┘ │
├─────────────────────────────────────────────────┤
│      ⦿ 喊话      ○ 语音      ○ 设置             │  ← DOCK 栏（三页切换）
└─────────────────────────────────────────────────┘
```

**语音页**：播报参数（语速/音调）+ 快捷语增删改 + 条目列表 + 预置语料恢复。
**设置页**：悬浮按钮（开关 + 透明度 + 尺寸）/ 启动行为（自动播报）/ 日志触发（开关 + 关键词 + 自定义 + 冷却）/ 音频路由诊断 / usage 遍历 / 外部触发命令 / 音频设备清单（可选用）/ 关于。

## 控件规范（Controls.kt）

| 控件 | 用途 | 关键规格 |
|---|---|---|
| `HollerCard` | 卡片容器 | R24 / Brand 渐变 / 1dp 描边 / 18dp 内边距；`elevated` 用 BrandElevated + 青绿描边 |
| `HollerSwitch` | 开关 | 52×30dp 胶囊 + 24dp 滑块；青绿=开，Stroke=关；spring 动效 |
| `HollerSlider` | 滑块 | 轨高 8dp、触控区高 40dp（车机手指精度低）、22dp 拇指；右侧实时数值 |
| `HollerChip` | 多选一 | R14 胶囊；选中 = 青绿描边 + AccentSoft 底 + 0.97 缩放 |
| `HollerButton` | 行动按钮 | primary 实心青绿/深色字；非 primary 描边；`danger` 变红 |
| `StatusPill` | 状态点 | 10dp 圆点 + 文字，顶栏常驻 |
| `LabelValueRow` | 标签值行 | 左次要文字 12sp、右主文字 12sp |
| `MiniAction` | 列表行内小按钮 | 单字（▶ 改 ★ ×）34dp 方块；多字（选用/已选）56×34dp |
| `CountdownRing` | 录音倒计时环 | 212dp；底环 Stroke 细线 + 进度弧状态色；最后 3 秒转 danger 红；圆心显示剩余秒数 |
| `MiniRing` | 紧凑进度弧 | 纯弧无文字，留给 DOCK / 悬浮窗等小尺寸场景 |

> **纪律**：所有「面」用 Brand / BrandElevated，强调色只做「点」（选中态、状态点、数值）。新增控件必须复用这些积木，不引入新视觉语言。

## 交互规则

- **主按钮**：按住说话（Push-to-Talk），松开即播；按住时描边变 `danger` 红，播报时变 `accent` 绿
- **倒计时环**：录音时外圈环顺时针推进，圆心显示剩余秒数；**最后 3 秒整环转 `danger` 红**给出收尾提醒（`HollerEngine.MAX_SECONDS = 15`）
- **状态即时反馈**：顶栏状态点 —— 待命（灰）/ 录音（danger 红）/ 播放（accent 绿），任何页面可见
- **诊断信息**收进设置页，保持喊话页干净
- **无网络依赖**：全程本地，不做登录、不做云同步

## 与 Flyme Auto 的差异说明

Holler 是**第三方应用**，不是系统级 UI，因此：

- 不追求 3D 实况桌面、动态壁纸（那是系统能力）
- 不做小窗模式（需系统权限）
- **专注座舱音频体验**：把「喊话 + 变声 + 快捷语」这条链路做到顺畅
