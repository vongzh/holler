P0

底栏选中态语义拆分

P1

现状一种绿色表达两种含义：「大叔」绿 = 变声效果已启用（持久），「快捷语音」绿 = 面板展开中（临时）。 面板一关绿就消失，而隔壁的绿却一直在——用户会误判成三个 tab。建议拆成两套视觉：面板展开 = 浅底 + 文字加粗（现有 BrandElevated，无需新增令牌）； 效果启用 = 右上小圆点（Accent，5dp）。文字回归中性色，让「点」只表达持久状态。

浅色主题主按钮边界

P1

白渐变圆落在 #F2F5F8 背景上，实测只有约 1.06:1 的明度差；代码里其实一直有 1dp Stroke 描边，但 #D6DFEB 对 #F2F5F8 仅约 1.17:1，等于看不见——所以白天强光下按钮边界会消失。 落地采用 D 方案（补充柔投影）：不动描边与渐变令牌，用一层 14dp 的暖灰投影把圆钮从浅底上托起来； 深色主题下黑投影不可见，零副作用。A 方案（加深描边）仍在候选，B/C 已否决。
